# Support ArxLang

## Help build the next generation of open compiler tools

ArxLang is working toward a language and compiler ecosystem that makes native,
data-oriented programming more accessible. Building it takes sustained work on
the language frontend, ASTx, IRx, LLVM integration, Arrow-backed runtime,
testing, developer tools, and clear learning resources. Contributions help us
dedicate time to making that foundation more reliable and useful.

**[Support ArxLang on Open Collective](https://opencollective.com/osl/projects/arxlang/donate?interval=month&amount=20&name=&legalName=&email=)**

You can make a one-time donation or choose recurring support. Both help keep
development moving; recurring contributions are especially valuable for planning
long-term maintenance.
