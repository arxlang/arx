Built-in Types

Built-in Types

Choose explicit scalar types for arithmetic and annotated collection types for stored data. Accepted type spellings live in packages/arx/src/arx/lexer/syntax.json; a lexical name alone does not establish executable support. See the capability matrix for that boundary and type annotations for placement.

Scalars and conversions

Use fixed-width integers or floats when width matters, bool for conditions, and str for UTF-8 text. char is a low-level i8 representation, not a Unicode grapheme. none is both the unit type and its sole value; a -> none function may use bare return, return none, or fall through.

cast(value, Type) requests a supported conversion. isinstance(value, Type) checks the semantic type, including finite union aliases; type(value) returns its name. These do not introduce dynamic Python objects or runtime tagged unions. See the executable datatype tests and preview arithmetic contract.

Strings have distinct static, borrowed, and owned lifetimes; consult the string ownership contract before returning or storing borrowed text. Native strings cannot represent embedded NUL safely.

Collections and nullable values

Collections and Apache Arrow owns the list, tensor, DataFrame, and Series storage rules. In particular, runtime-schema DataFrames support locals and returns, while runtime-shaped tensors remain parameter-only. Temporal and rich Arrow column schemas do not imply general temporal or nested scalar operations.

Nullable expressions carry explicit validity, propagate nulls, and use checked arithmetic. They are not interchangeable with non-nullable scalar arithmetic or Boolean conditions.

File references

File and open create shared class references to one text stream; lowercase file denotes the same type. References can be aliased, passed, returned, and stored in supported class fields. Closing through any alias closes the shared stream. Only the hidden native handle is uniquely owned.
