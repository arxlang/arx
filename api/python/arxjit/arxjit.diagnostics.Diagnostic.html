python:arxjit:arxjit.diagnostics.Diagnostic

class Diagnostic

Diagnostic(severity: DiagnosticSeverity, message: str, filename: str, line: int | None, column: int | None, code: str | None = None)

Source: packages/arxjit/src/arxjit/diagnostics.py:28

One structured diagnostic reported by arxjit.

Attributes

  • severity — Type: DiagnosticSeverity; The severity level of the diagnostic.

  • message — Type: str; The human-readable diagnostic message.

  • filename — Type: str; The file defining the decorated function, or "<unknown>" when the source cannot be attributed.

  • line — Type: int | None; One-based source line in filename, when known.

  • column — Type: int | None; One-based Unicode character column in line, when known. Python AST col_offset values (zero-based UTF-8 byte offsets) must be converted to this representation at the boundary that produces the diagnostic, never stored raw.

  • code — Type: str | None; Stable diagnostic code, e.g. "AJ001", when assigned.
